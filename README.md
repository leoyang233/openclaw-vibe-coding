# 带着地图读三国

将《三国演义》文本与交互式地图结合，让读者在阅读经典名著时直观感受魏蜀吴三国疆域与战路走向。

## 核心功能

- **阅读模式 + 地图联动**：阅读原文时，点击地名自动在地图上定位并显示介绍
- **古今地名映射**：三国地名对应现代地理位置，消除历史地理鸿沟
- **势力范围可视化**：魏/蜀/吴疆域分色显示
- **人物位置标注**：曹操、刘备、孙权、诸葛亮等关键人物一目了然

## 技术栈

- Leaflet.js 交互地图（CDN引入，开箱即用）
- 纯 HTML + CSS + JS 单文件，无需构建
- GeoJSON 绘制势力范围多边形
